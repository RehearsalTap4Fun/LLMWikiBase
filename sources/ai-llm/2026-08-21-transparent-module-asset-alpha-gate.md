# AI 透明模块素材的 Alpha 门禁与失败边界（2026-08-21）

- 回顾范围：2026-08-20 21:31 至 2026-08-21 21:31（Asia/Shanghai）
- 来源：QMonster Creator 透明部件素材垂直切片失败复盘
- 类型：AI/LLM 使用经验原始总结

## 1. 棋盘格观感不能证明图片透明

生成提示词明确要求“透明背景”，输出画面也出现灰白棋盘格，仍可能只是模型把棋盘格画进了普通 RGB 图片。视觉上像透明和文件实际含有 Alpha 通道是两回事，必须由机器读取通道和像素证明。

最低门禁包括：能够正常解码、存在 Alpha 通道、透明像素确实存在、画布边缘没有被不透明背景填满。只有 `hasAlpha=true` 仍不够，因为图片也可能带一个全不透明的 Alpha 通道；应继续检查 Alpha 的取值范围和边缘透明度。

## 2. 先做单个垂直切片再批量生产

模块化素材比整张角色图要求更高：除了风格正确，还要满足固定镜头、真实透明、可拆分边界、锚点一致和独立组合。正式批量生成前，应先完成一个最小闭环：锁定母体、生成单个区域变化、验证透明通道、转换运行时格式、写入目录并完成一次真实拼装。

如果第一个样板无法通过透明和组合门禁，继续批量生成只会放大返工。此时应停止在素材入口，不让不合格图片进入正式目录，也不应因为下游转换脚本运行成功就把源素材视为合格。

## 3. 格式转换不能创造缺失的透明信息

把 RGB PNG 转成 WebP，或给图片机械添加一个全不透明 Alpha 通道，并不能恢复被背景覆盖的主体边缘。真实透明信息在生成或可靠抠图阶段就必须存在。

色键抠图也不是无条件补救：背景颜色可能进入主体高光、半透明材质和抗锯齿边缘，自动删除会损坏轮廓。除非任务明确授权并有视觉复核，否则不能用色键结果冒充原生透明素材。

## 4. 失败必须保留在正确的阶段

素材生成失败时，可以保留已经验证独立成立的工作，例如美术规范、提示词模板和格式转换测试；但不能提交一套看似完整、实际缺少合格源素材的正式目录。完成状态应按模块拆分：规则和转换工具可以标记完成，生产目录仍保持阻塞。

当内置工具连续无法提供真实透明输出，而替代方案需要新的凭据、接口或处理方式时，应暂停并请求用户授权。不能因为目标紧迫就擅自切换生成通道、读取未授权凭据或降低质量门槛。

## 5. 透明素材应保留可追溯证据

每个通过门禁的素材应记录来源提示词、母体版本、处理版本、实际编码格式、尺寸、通道信息和内容哈希。批次验收可以生成接触表供人工检查风格、光向、接缝和透明边缘，但人工观感与机器校验应并列，不能互相替代。

可复用原则是：把透明度视为文件事实，而不是提示词意图或画面风格；先用垂直切片证明生产链，再扩大批量。
