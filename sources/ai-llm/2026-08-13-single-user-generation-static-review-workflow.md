# 单人 AI 生成工具的复杂度预算与静态批量审核（2026-08-13）

- 回顾范围：2026-08-12 21:31 至 2026-08-13 21:32（Asia/Shanghai）
- 来源：历史人物形象传记生成器首批名册生产与审核流程重构
- 类型：AI/LLM 使用经验原始总结

## 1. 人工门禁不等于必须建设重型审核系统

单人、本地、低并发的 AI 生成工具，往往只需要“准备物料、查看成果、批准或驳回、按意见重做”这条闭环。动态服务、数据库状态机、自动评分、逐项审核表单、核验包和多层镜像记录虽然都能增加控制力，但当同一个人既是操作者又是审核者时，也会制造重复确认和维护成本。

更合适的最小结构可以只有三层：人物资料、静态审核物料、单一审核结果文件。静态页面负责展示图片、传记、提示词和来源；结果文件记录通过、驳回和待处理状态。下一轮 Codex 只读取结果文件，归档通过项、重做驳回项并跳过待处理项。

## 2. 事实审核和成果审核应当各做一次

人物事实、视觉方向和版权边界在生成前批准后，不应在传记审核、图片审核和最终归档阶段反复要求用户重新确认同一内容。

可复用的分层是：

- 生成前审核人物资料与允许使用的事实；
- 生成后只判断当前成果是否可接受；
- 归档只消费已经明确的审核结果，不再增加新的判断门槛。

技术校验可以保证文件完整、结果属于正确人物，但不能把用户的审美决定拆成大量必填证据。审核界面的主要动作应保持为“通过”和“驳回并重绘”。

## 3. 固定防错约束应前置到提示词

完整全身、正常肢体、兵器真实握持、核心身份线索、时代边界、无文字水印等固定要求，应成为所有生图提示词的统一约束块。角色提示词只负责人物身份、姿态、场景、装备和品质色彩。

前置约束不能保证模型一定正确，因此人工终审仍需保留；但它能避免生成后再让用户逐项填写相同的检查表。机器只负责尽量生成符合约束的候选，最终视觉判断交给人。

## 4. 重绘方式应由问题类型决定

“参考旧图修改”和“完全重新生成”不是同一种修订方式：

- 配色、氛围、局部装饰等问题适合参考旧图修改，以保留已有构图和人物一致性；
- 手与兵器、骑手与缰绳、人体与坐骑等结构关系反复错误时，应完全重新生成，避免旧图中的错误结构持续约束新结果。

审核结果应同时保存修改意见、用户修订后的提示词和所选重绘方式，让下一轮执行严格消费这些输入，而不是自行猜测用户想保留哪些部分。

## 5. 批次画廊优于大量单人页面

当审核对象属于同一批次时，一个批次画廊比每人一个入口更易维护。画廊应支持：

- 同页浏览全部人物成果；
- 按待审核、已通过、已驳回筛选；
- 一键通过全部待审核项；
- 单人驳回、修改提示词并选择重绘方式；
- 加载旧结果并增量覆盖同一份批次审核文件；
- 对缺少物料的人物显示待生成，而不是维护另一套入口。

单一结果文件也让自动化更容易保持幂等：每次加载现有状态、合并本次修改，再覆盖保存，不需要同步多个单人状态文件。

## 6. 简化前先定义目标结构和可恢复边界

从重型系统收敛到静态流程时，应先列出最终保留结构，再清理旧服务、状态目录、中间图片和重复产物。清理动作必须在用户明确确认后执行，并确保仍可从版本历史恢复。

可复用原则：先按真实使用频率给流程分配复杂度预算。只有确实需要多人协作、无人值守、强审计或跨会话恢复时，才逐步引入动态服务和状态机；不要让原型阶段的控制机制反过来成为主要工作量。
