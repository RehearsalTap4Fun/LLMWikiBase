# 程序化生物应按规则单次生成，再由用户终审（2026-09-01）

## 背景

一批随机 Q 版生物按固定种子和显隐性特征规则生成后，视觉复盘发现主要问题并非随机性不足，而是脸部语义没有被锁定在连续头部区域：部分表皮、纹样和特效形成类似牙齿或嘴唇的重复结构，造成多个视觉中心。后续修复同时涉及素材语义、组合预算、脸区检查和发布验收。

## 可沉淀经验

### 1. 随机丰富度必须服从唯一视觉中心

眼睛、嘴型和口腔细节应组成完整脸组，并共享同一连续脸区。身体纹样、表皮和特效可以丰富轮廓，但不能偶然形成第二张脸；双头或异位眼只能由明确变异规则产生，不能依赖随机装饰误读。

### 2. 全局预算之外还要有分类预算

只限制全身强特征总量，仍可能让多个强身体装饰同时抢占脸部注意力。应为非脸部强特征单独设置预算，并让候选筛选、首次生成、锁定预留和重抽都遵守同一规则，避免只修一个入口。

### 3. 自动门禁负责客观约束

机器适合检查脸区内占比、可见度、遮挡、面积、强度预算、组合兼容和确定性。它不适合替用户决定“是否好看”或“是否像完整生物”。自动指标应阻断客观违规，但不能伪装成审美批准。

### 4. 单次生成与用户终审要明确分层

完成规则和素材调整后，只生成一次固定种子批次，输出联系表、规格和清单，并标记为等待用户审核。系统不应因为自己的视觉判断反复抽取种子或悄悄重生成，否则最终样本会被无形筛选，既破坏随机分布，也让用户无法判断规则本身是否有效。

### 5. 旧版本证据必须保持冻结

视觉规则升级应使用新的目录与渲染版本，旧素材、旧金图和旧审核证据保持不变。新批次通过用户终审后再形成新的批准记录，避免为了让新门禁通过而改写旧版基线。

## 适用场景

适用于随机宠物、怪物、头像、皮肤组合和其他配置驱动的批量形象生产。核心原则是：规则保证可用，自动门禁保证客观合规，用户决定审美是否通过。
